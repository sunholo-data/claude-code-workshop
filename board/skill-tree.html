Start here: get the workshop onto your laptop
  1. In Claude Desktop, click Code (the </> button, top left). Click + New, choose This computer and an empty folder, such as claude-test in Documents. Then click the mode button that says Auto and choose Manual.
  2. Send this. Claude shows you a git clone command first: read it, then allow it.
    Clone https://github.com/sunholo-data/claude-code-workshop into this folder, then tell me how to start the workshop.
  3. Click + New again. Click the folder button (it still says claude-test), choose Open folder…, and pick claude-code-workshop inside it. Then send this, and choose Trust workspace when asked:
    start the workshop
    The guide asks to create progress.md, your own record. Allow it.

Git not working yet? On the course repo, click Code then Download ZIP, unzip it, and choose that folder in step 3.
